# forkliftdriftinggame
This is a game where you can drift a forklift

## Mini-games

- **Keep the Baby from the Can** — a single-file 3D mini-game built with Three.js and Cannon.js. Open [`keep-the-baby-from-the-can.html`](./keep-the-baby-from-the-can.html) in a modern browser. Click and drag the baby to nudge it away from the can sitting near the fireplace; tap empty floor to push the baby away from that point.
